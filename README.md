# UniLearn
Student Learning Management System (SLMS)

<img width="906" height="312" alt="UniLearn_logo" src="https://github.com/user-attachments/assets/53a196a2-dc2b-4be3-be71-025713396e28" />

UniLearn is a system designed to manage university teaching and learning activities. It allows students to enroll in courses, access materials, and submit assignments, while lecturers can manage content, assessments, and grades. 

The system provides a centralized platform to improve communication, organization, and overall learning efficiency within the university.
